# Sprint 1 Evidence Checklist

Use this checklist when validating Sprint 1 completion across backend and monitoring repos.

## Contract and standards

- [ ] Backend telemetry contract is merged
- [ ] Monitoring observability standards are merged
- [ ] Contracts are aligned on labels and route normalization

## Metrics baseline

- [ ] `/api/v1/metrics` exposes RED metrics
- [ ] Route labels are normalized templates (no raw IDs)
- [ ] Error counter present and split by error type

## Correlation baseline

- [ ] Request ID is accepted or generated by backend
- [ ] Response includes `X-Request-ID`
- [ ] Error payload includes `requestId` when available

## Security and exposure

- [ ] Public endpoint is Grafana only
- [ ] Internal services are not publicly exposed
- [ ] Metrics access restricted at network/proxy level
- [ ] Metrics endpoint has app-layer auth in backend

## Attachments for sprint closure

- [ ] `/metrics` text snippet (representative sample)
- [ ] 10 sample logs containing `requestId`
- [ ] test/build command outputs for baseline changes
